L~ (Ltilde)

A programming language developed by LUMEN.

L~ (pronounced Ltilde) is an independent programming language project created by LUMEN, focused on language design, programming concepts, and execution architecture.

The project is built through continuous experimentation, implementation, and refinement.

About

L~ is designed around an imperative and procedural programming model, with features that include functions, closures, structured data types, pattern matching, and static type checking.

Its development explores the components behind a programming language, from lexical analysis and parsing to compilation and execution.

Features

The current implementation includes:

- Custom lexer and parser
- Abstract Syntax Tree (AST)
- Static type checking and type inference
- Bytecode compiler and virtual machine
- AST interpreter
- Functions and closures
- Structs and enums
- Generic functions
- Conditional statements and loops
- Pattern matching
- Module system
- Command-line interface (CLI) and REPL

Architecture

L~ includes its own language processing and execution components:

- Lexer: tokenizes source code.
- Parser: analyzes syntax and builds the AST.
- Type Checker: performs static type validation and inference.
- Compiler: translates programs into bytecode.
- Virtual Machine: executes compiled bytecode.
- Interpreter: provides an alternative AST-based execution path.
