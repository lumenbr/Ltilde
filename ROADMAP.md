L~ (Ltilde) — Roadmap

This document outlines the planned development direction of L~. Priorities may change as the language evolves and new technical requirements emerge.

Current Stage — Alpha

Current version: 0.6.0-alpha

Focus:

- Consolidating the existing language implementation
- Improving compiler and virtual machine reliability
- Refining type checking and diagnostics
- Expanding test coverage
- Improving documentation and examples

Short-Term Priorities

- Improve language consistency and syntax
- Expand standard library functionality
- Improve error messages and diagnostics
- Refine module handling
- Optimize bytecode execution
- Address known limitations in the current implementation

Mid-Term Goals

- Develop additional developer tools
- Improve debugging and development workflows
- Expand language capabilities
- Refine compiler and runtime architecture
- Improve interoperability possibilities

Long-Term Vision

- Progress toward a stable language release
- Explore alternative compilation targets
- Expand the standard library and ecosystem
- Improve tooling and development experience
- Establish a broader technical foundation for future applications

Development Principles

L~ development follows these principles:

- Consistency: maintain a coherent language design.
- Reliability: prioritize correctness and predictable behavior.
- Clarity: provide understandable syntax and diagnostics.
- Evolution: introduce improvements through continuous development.
- Experimentation: explore technical possibilities while preserving architectural coherence.

Notes

This roadmap represents development intentions, not guaranteed release commitments.

Features and priorities may be revised as the project progresses.
